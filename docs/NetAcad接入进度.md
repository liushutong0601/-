# NetAcad 网页适配预览

2026-11-20，源码版本 `1.2.0.dev16`。已接入桌面窗口，属于新增平台预览。已有 EXE 不会随源码更新，使用新增功能需运行当前源码或单独构建的预览包。

`dev2` 修复文章和隐藏标题共用 `modelid` 时的定位冲突：阅读范围及滚动只定位 `article-view`，答案绑定只定位相应的题目组件。同类目标仍不唯一时暂停，定位或滚动未完成时不推进节点游标。

`dev3` 新增逐题解锁考试：从当前工具栏读取“第几题 / 本轮总题数”，允许导航随单题保存逐步增加，普通试卷仍须完整导航。题数不会固定为某个值，重开后重新读取。普通导航延迟时等待而非立即报错；已有试卷的离屏开始按钮不会被误点。

`dev4` 兼容题号放在题目组件的 `.component__title-inner`、没有 `.block__title-inner` 的页面；组件题号和外层题号冲突时仍暂停。切题时只将当前屏内组件作为上一题身份，避免离屏缓存题在回访复核时被误判为旧内容未更新。本次在真实页面只读提取了当前第 1 题的单选结构及 4 个选项，校验通过且点击次数为 0，未填写或提交。

`dev5` 修复最终导航的辅助名称包含“已选中”前缀、文字带尾部空格时的误判。最后一题保存后，出现确认框也可作为到达最终页的明确信号。真实模式完整复核后自动勾选 `confirm-exam`，等待按钮移除禁用状态，再点击一次最终提交；结果未知时不重复点击。恢复运行时，只有待提交确认框未勾选、导航明确全部已作答、全部现有答案完整且合法，才能恢复本轮提交，不重新调用 AI。测试模式不勾框、不提交。已有可见成绩时禁止再次提交，满分时提示进入下一待完成节点。

`dev6` 接入独立检查点目录：真实页面中的检查点按钮没有 `aria-expanded`，以其 `subModuleContainer--*` 的 `active--*` 选中状态定位；同名检查点按按钮标识和名称一起区分。普通小节使用同一选中逻辑，只有没有选中容器的兼容页面才回退到唯一展开项。完成状态也从该选中节点读取，不能把 `100 Pts` 分值徽标当作成绩。开始、答题、保存、提交、解析和重做沿用既有测验流程，题数动态读取。

本地合成页面验证了独立检查点在无展开属性、其他小节仍展开、重复名称、选中节点切换，以及 33 题开始页切入题目导航时的行为；测试模式不会启动计时考试。真实开始页已只读核实：选中检查点状态为待完成，动态声明 33 题，开始按钮可用，节点识别为考试；没有启动真实计时考试、调用 API 或提交。

## 使用步骤

`dev16` 支持从小节检测结果页的题号读取判定。确认已有成绩及结果导航后，复用已判对和已公布答案的题，重新解答未确认的题。仅有分数的页面可以在检查整卷结构后进入新一轮。自动重置和提交在合成页面验证。

`dev15` 增加逐行下拉匹配题。已通过专用 Edge 只读核实真实组件、菜单和选中状态。填写、逐题保存、提交和按公布的分类表重做均在合成页面验证。

`dev11` 支持直接答带 PT 下载入口的网页题。逐题保存时核对实际选中状态，最后依据保存记录和网页已作答标记自动勾框提交，省去整卷回翻。成绩未满分时读取平台公布的选项标记和配对解析表，再到结果页重置并填完整份测验。配对描述重名时使用与解析表一致的原始类别序号。重做按当前题目和选项映射已确认的答案，仅在缺少可靠答案时调用 API。真实页面已核实成绩页、错题状态和配对解析表结构，自动重置和提交在合成页面验证。

平台显示“请重新启动课程以记录您的进度”时，在专用 Edge 中重新进入课程和当前测验，再用软件继续。

`dev10` 修复选择选项或读取图片时滚动导致的误暂停。当前题组件仍可唯一定位时，直接校验其题号、题干和选项并操作，无需再点击题目导航。重新开始后优先从页面缓存读取旧题答案，直接处理当前未保存题。缓存不足时先答剩余题，最终提交前再补齐旧题答案和结构校验。真实中途页面的缓存恢复已通过只读检查，核查过程中未切换题目。

`dev9` 明确模式区别：NetAcad 测试模式的主按钮为“预览答题（不保存）”，常显说明逐题考试只预览当前题、不解锁后续题。测试结束时日志和状态栏都会说明整份测验尚未完成，并指引选择“真实提交模式”后点击“开始答题并提交”并确认。默认仍为测试模式，不自动切换真实提交；预览结束保留窗口。要继续整卷必须使用真实提交模式，因为逐题解锁需要实际保存当前题。

`dev8` 增加逐题考试中途续答：当前停在最后一个已解锁题目，且此前连续题目明确显示已作答时，只读提取并校验旧题的现有选中答案，重建本轮保存记录，再从当前题继续。已保存题目不重新求解、填写或保存。配对答案仍须完整且一一对应。当前题的“已选中”辅助名称可能覆盖 `answered`，程序在离开该题后再核实作答标记。`answered` 只表示已有选择；前面题目已保存还需要后续题已经解锁这一依据，不能把当前题仅有已选答案当作已保存。当前题存在提交或组件禁用标记、保存入口忙碌、加载尚未结束时暂停；未选答案导致保存按钮暂时禁用属于正常状态。测试模式仅恢复和预览当前未保存题，不保存新题；恢复过程中停止后不进入后续答题或保存。

`dev7` 识别播放器将 `is-submitted` 和 `show-user-answer` 拼接的已提交状态。非满分时读取每题判定，即使没有文字解析也记住已判错的完整答案组合；按题干、题型和选项内容关联，新轮次选项换序时重新映射字母。明确正确的答案可直接复用，其余题目交给 API 重新解答。若 API 再给出已经判错的组合，验证不通过，不填写或提交。多选只排除完整组合；配对组未全对不代表每一类别均错，因此不对各类别的旧选项作强制排除。

记忆只保留在当前测验本次运行的内存中，不保存课程题目或答案到磁盘。题目内容重复时不沿用记忆；图片仅在截图完全一致时关联，重新布局或选中样式变化可能使其重新求解。已提交的成绩页、错题查看页也能恢复：先读取已有成绩、全部所选答案和判定，再进入最多 3 次重做；测试模式只读取已有判定，不重置或提交。已有明确满分时不再调用 AI 或重复提交。

填写后的选中状态经过一次真实 DOM 复核便生成变更凭据。后续保存或提交只核查凭据，页面未变化时不反复切题；选中属性、题干、选项、图片或组件节点发生变化时凭据失效并重新复核。页面若切题时销毁组件也会触发重读。逐题解锁后的标题和旧组件身份在同一次 DOM 读取中取得，避免自动切题发生在两次读取之间导致等待错误的旧组件。

1. 平台选择“Cisco NetAcad（网页适配预览）”，点击“启动专用浏览器”，在专用 Edge 中自行登录并打开课程。
2. 点击“解析当前章节”可做只读结构检查，不开始考试、不调用 AI、不填写或提交。
3. 默认测试模式：阅读页停在原节点，避免滚动写入进度；已经打开的测验可调用 API 填写并复核，随后保留页面，不提交、不重做、不导航。逐题试卷只预览当前可用题，不执行单题保存来解锁后续题。尚未开始的计时考试不会在测试模式下自动启动。
4. 需要实际处理课程时，先检查 API 配置，再选择真实提交模式。启动前的确认会说明开始计时考试和重做次数；确认覆盖本次运行。运行中可点击停止。
5. 高级设置中的重做次数默认 3，含义为首次答题之后最多再做 3 次，总计最多 4 轮；达到上限仍未满分则停在当前测验。

AI 答案不保证正确。图像输入已接通，但真实服务的视觉能力、账号权限和额度需要单独验证。该预览不能视为真实课程所有节点均已验收。

## 已实现的流程与网页结构

- `autoquiz/course.py` 独立于原有学习通流程。已完成阅读节点根据目录明确标记跳过；未知状态暂停。
- 阅读节点逐段向下滚动，反复检查目录完成标记。滚到底仍未完成时暂停；离开小节前还要核实整个小节已完成，避免遗漏延迟加载的子节点。
- `autoquiz/netacad.py` 遍历开放 Shadow DOM，处理已核实结构的单选、多选、连线配对、下拉匹配、图片题，以及开始页、逐题导航、提交确认页、成绩页、审查评估和重置入口。
- 普通分题考试以页面声明总数核对完整导航。逐题解锁考试根据当前工具栏与单题保存入口确认模式，逐题验证结构、答案和真实选中状态，再保存并等待下一题解锁。最终检查整卷保存记录和已作答标记。题干、选项及图片未就绪时等待。
- 逐题考试中途接入时，需核实前面题目连续已保存，再从当前未保存题继续。已保存答案可从缓存核对，缓存不足时延迟到整卷提交前读取。整卷答案不完整或保存状态不明时暂停。暂停或停止后已经发生的单题保存不会撤销。
- 连线配对题按类别拆分为内部答案项，同组实行一一对应。下拉匹配题逐行选择，各行可使用同一选项。填写后读取网页选中状态，通过复核后才保存整题。
- 所有答案完整、合法且与网页选中状态一致，才进入真实提交。行内练习的组件数量若在提取后变化或仍有加载请求，则暂停；勾选平台确认框后每轮只点击一次最终提交，结果未知时不重复提交。
- 成绩只读取当前可见结果。非满分时定位逐题错误或未全对的配对组。仅显示有效分数和完整结果导航的小节检测，可重新解答未公开判定的题。
- 重做会重新提取整份测验，复用明确判对的答案、重新解答其余题目，再完整填写并复核。反馈和禁止重复选择的组合按内容关联，不套用旧题号或旧字母；重复内容不自动沿用上轮反馈，图片需要截图完全一致。
- 操作前后检查停止信号，底层逐步操作也检查停止。已进入浏览器点击或网络请求的动作属于协作式取消，无法撤回已发生的操作。

## 本次范围与验证限制

带 `.pka` 或 `.pkt` 链接且可在网页内填写的题，按可见题干和选项作答。独立 Packet Tracer 实验需在外部软件中处理。自定义拖拽、排序、Canvas 题及其他未知组件没有通用适配。动画阅读若需要额外交互而无法产生完成标记，也会暂停。

真实课程仅做过只读结构核查，已识别当前小节的 4 个目录节点与待完成标记；未开始真实考试、未调用付费 API、未填写或提交真实课程。公开播放器模板提供了组件结构依据，入口为 https://www.netacad.com/authoring-resources/index.html 。真实课程兼容性仍需单独验收。

本次只读检查还核实了“当前第 1 题、总共 5 题、仅 1 个已解锁导航”的真实结构；修改后识别为逐题考试。没有在真实页面保存本题、解锁后续题目或最终提交。

后续现场核查确认了 `answered` 导航状态、未勾选的确认框，以及“已选中提交页面”的实际辅助名称。修复后准备恢复提交时，已发现可见结果页，因此没有再次点击最终提交。自动确认与中断恢复路径在合成 HTML 中验证，不能把现场已存在的结果归因于本次修复程序的提交。

`dev7` 在用户保留的已提交错题页完成了只读恢复核查：可读取本轮成绩、全部现有作答及逐题判定，拼接状态类的错题可以正确识别；没有文字解析时仍可定位错误。核查只切换结果页和题目导航，结束后回到原错题位置，未调用付费 API、重置、填写或提交。真实自动重做和再次提交仍需独立验收。

`dev8` 在真实中途暂停页面完成了只读恢复核查：此前连续已保存题目的答案可完整读取并通过校验，结束后仍停在原来的当前题。没有调用 API、修改选项、保存、重置或提交。此验证不代表后续所有题型和真实最终提交均已验收。

自动测试使用合成 HTML、独立无头 Edge 和模拟 AI，覆盖慢切题、声明题数不符、配对重复、已选单选修改、隐藏旧成绩、提交确认、停止、错题反馈和重做上限。测试通过不能推断真实 API 或所有真实课程可用。

`autoquiz/netacad_probe.py` 与 `tools/inspect_netacad.py` 为只读结构诊断：

```powershell
.\.venv\Scripts\python.exe -m tools.inspect_netacad
```

输出在 Git 忽略的 `logs/netacad-structure.json`，只保存结构计数、已知按钮与状态，不保存题干、答案键、登录资料、网址参数或账号信息。NetAcad 日常运行结果不持久化课程标题、节点标识或题目内容；题目和图片在答题时会发往用户配置的 API。
